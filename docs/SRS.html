1. المقدمة (Introduction)

1.1 الهدف من النظام (Purpose)

تمكين المعلمين والمؤسسات التعليمية من تحويل ملفات الـ PDF التي تحتوي على أسئلة اختيار من متعدد (MCQ) إلى اختبارات تفاعلية أونلاين فوراً، دون استخدام أي نماذج ذكاء اصطناعي خارجية (No AI Dependencies)، بالاعتماد الكامل على خوارزمية قطعية دقيقة وسريعة (Deterministic Regex & Text Parsing).

1.2 النطاق الأساسي (Scope)

  • رفع ملف PDF بهيكل ثابت واستخراج نصوص الأسئلة والخيارات ومفتاح الإجابات آلياً.
  • شاشة مراجعة للمعلم لتعديل الأسئلة، تحديد الإجابة النموذجية، وضبط درجات كل سؤال.
  • توليد كود دخول فريد (Access Code) لكل امتحان ومشاركته مع الطلاب.
  • واجهة مخصصة للطلاب لحل الامتحان مع عداد تنازلي نشط وتسليم تلقائي عند نفاد الوقت.
  • تصحيح آلي فوري وإصدار تقرير الفيدباك والنسبة المئوية فور تسليم الطالب.
  • لوحة تتبع للمدرس (Tracker) لمعرفة الطلاب الذين أتموا الحل والأسئلة الأكثر خطأً.

2. المعمارية المعتمدة (4-Layer Clean Architecture)

تم تطبيق معمارية الـ 4 طبقات النظيفة في منصة .NET لضمان سهولة الصيانة وقابلية الاختبار:

+---------------------------------------------------------------------------------+ | QuizPlatform.API (Controllers) | | ExamsController, SubmissionsController, AnalyticsController | +---------------------------------------------------------------------------------+ | v +---------------------------------------------------------------------------------+ | QuizPlatform.Application (BLL) | | ExamService, SubmissionService, AnalyticsService | | DTOs (ExamDtos, SubmissionDtos, TrackerDtos) | +---------------------------------------------------------------------------------+ | | v v +------------------------------------+ +----------------------------------------+ | QuizPlatform.Infrastructure | | QuizPlatform.Core | | - AppDbContext (EF Core) | | - Entities: Exam, Question, Option, | | - Repositories: Exam, Submission |-->| Submission, StudentAnswer | | - PdfParserService (PdfPig) | | - Enums: QuestionType, ExamStatus | | - SQLite Database | | - Interfaces: IRepository, IExamRepo | +------------------------------------+ +----------------------------------------+

3. المتطلبات الوظيفية (Functional Requirements)

الرمز اسم الميزة الوصف والتفاصيل
FR-01 استخراج الـ PDF بدون AI استخراج الأسئلة والخيارات (A, B, C, D أو أ، ب، ج، د) ومفتاح الحل بنمط Regex ومكتبة UglyToad.PdfPig.
FR-02 مراجعة وتعديل الأسئلة إتاحة تعديل نصوص الأسئلة والخيارات وتحديد الإجابة الصحيحة والدرجة قبل النشر.
FR-03 توليد كود الدخول (Access Code) توليد كود فريد (مثل: QC-583921) يتيح للطالب الدخول مباشرة للاختبار.
FR-04 واجهة حل الامتحان للطالب حجب حقل IsCorrect في كائن TakeExamDto لمنع الغش البرمجي.
FR-05 مؤقت الامتحان والتسليم التلقائي عداد تنازلي نشط يقوم بتسليم الامتحان تلقائياً فور انتهاء الوقت المحدد.
FR-06 التصحيح التلقائي الفوري مقارنة إجابات الطالب بالنموذج، احتساب الدرجة والنسبة المئوية، وتحديد حالة النجاح فوراً.
FR-07 شاشة تتبع الطلاب والتحليلات عرض قائمة الحضور، نسب النجاح العامة، وتحديد السؤال الأكثر صعوبة (Hardest Question).

4. المتطلبات غير الوظيفية (Non-Functional Requirements)

المعيار المواصفات المستهدفة
الأداء (Performance) استخراج ملف PDF يحتوي على 50 سؤالاً في زمن يقل عن 1.5 ثانية بدون استدعاء سيرفرات خارجية.
الأمان (Security) عدم تسريب الإجابات الصحيحة في الـ API المخصص للطلاب عبر عزل نماذج الـ DTOs.
الاعتمادية (Reliability) الاعتماد على مكتبة مفتوحة المصدر نقية C# بدون مكتبات تشغيل خارجية إضافية.
سهولة الصيانة (Maintainability) فصل طبقات المعمارية النظيفة بحيث يمكن تغيير قاعدة البيانات دون لمس الـ Core أو الـ API.

5. مخطط الكيانات وقاعدة البيانات (Database Entities)

  • Exam: Id, Title, AccessCode, DurationMinutes, TotalMarks, PassPercentage, Status, CreatedAt.
  • Question: Id, ExamId, QuestionNumber, Text, Type, Points, Explanation.
  • Option: Id, QuestionId, Label (A/B/C/D), Text, IsCorrect.
  • Submission: Id, ExamId, StudentName, StudentIdentifier, Score, TotalMarks, IsPassed, AutoSubmittedDueToTimeout.
  • StudentAnswer: Id, SubmissionId, QuestionId, SelectedOptionId, EarnedPoints, IsCorrect.
